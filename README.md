# LightFoot Sender v1.2.3 — Инструкция для разработчика

## Сборка .exe (2 команды)

Открой папку проекта в терминале и выполни по порядку:

```bash
npm install
npm run build
```

Готовый установщик появится здесь:
```
dist/LightFoot-Sender-Setup-1.2.3.exe
```

Этот файл передаётся пользователю. Больше ничего не нужно.

---

## Что получит пользователь

- Двойной клик на `.exe` → стандартная установка Windows
- Ярлык на рабочем столе и в меню Пуск
- Node.js, терминал, npm — **не нужны**
- При первом запуске WhatsApp Web попросит сканировать QR-код (один раз)

---

## Структура проекта

```
lightfoot-sender/
├── main.js          — Electron главный процесс
├── preload.js       — мост renderer ↔ main
├── whatsapp.js      — Playwright: сбор контактов + отправка
├── package.json     — зависимости + конфиг сборки
└── renderer/
    ├── index.html   — интерфейс
    └── app.js       — логика UI
```

---

## Требования к машине разработчика

- Node.js 18+ (скачать на nodejs.org)
- Windows 10/11 (сборка под Windows делается на Windows)
- ~500 МБ свободного места (Electron + Playwright chromium)

---

## Если сборка падает

**Ошибка иконки** — добавь файл `assets/icon.ico` или временно убери `"icon"` из `package.json`.

**Ошибка Playwright chromium:**
```bash
npx playwright install chromium
npm run build
```

**Повторная сборка после изменений:**
```bash
npm run build
```
Пересборка занимает ~1 мин (Electron кешируется).

# ОРИГИНАЛЬНАЯ ИНСТРУКЦИЯ ДЛЯ ПОЛЬЗОВАТЕЛЯ (архив)

## Что это такое

**LightFoot Sender** — инструмент для WhatsApp-рассылки.  
Позволяет: собрать базу контактов из чатов → написать несколько вариантов сообщения → запустить рассылку.  
Работает через WhatsApp Web. Сессия сохраняется — QR-код сканируется только один раз.

---

## 1. Установка Node.js

1. Откройте сайт: **https://nodejs.org**
2. Скачайте версию **LTS** (рекомендуемая)
3. Запустите установщик, нажимайте «Далее» — всё оставляйте по умолчанию
4. После установки: нажмите `Win + R` → введите `cmd` → нажмите Enter
5. Введите `node --version` — должно показать версию, например `v20.11.0`
6. Введите `npm --version` — должно показать версию, например `10.2.4`

Если команды не работают — перезапустите компьютер.

---

## 2. Установка зависимостей

1. Откройте папку проекта `lightfoot-sender`
2. Нажмите `Shift + ПКМ` в пустом месте папки → «Открыть окно PowerShell/командной строки»
3. Введите команду:

```
npm install
```

4. Подождите 2–5 минут — устанавливаются все необходимые компоненты
5. Затем установите браузер для автоматизации:

```
npx playwright install chromium
```

Это скачает браузер (~120 МБ). Нужно только один раз.

---

## 3. Запуск для проверки (без сборки)

```
npm start
```

Приложение откроется. Можно пользоваться сразу.

---

## 4. Сборка .exe файла

Для создания установочного .exe файла:

```
npm run build
```

Файл появится в папке `dist/` — называется `LightFoot-Sender-Setup-X.X.X.exe`

**Примечание:** первая сборка занимает 5–15 минут (скачивает Electron ~80 МБ).

Для быстрой проверки без установщика:
```
npm run build:dir
```
Создаст папку `dist/win-unpacked/` — запускается `LightFoot Sender.exe` напрямую.

---

## 5. Как пользоваться

### Шаг 1 — Подключение

1. Запустите приложение
2. Перейдите в раздел **«Подключение»**
3. Нажмите **«Открыть WhatsApp»** — откроется браузер с WhatsApp Web
4. На телефоне откройте WhatsApp → три точки → **«Связанные устройства»** → **«Привязать устройство»**
5. Отсканируйте QR-код на экране
6. В приложении появится статус **«Подключено»** (зелёный)

> Сессия сохраняется. При следующем запуске QR-код не нужен — WhatsApp откроется сразу.

---

### Шаг 2 — Сбор контактов

1. Перейдите в **«База контактов»**
2. Выберите фильтры:
   - **Период** — за сколько дней собирать чаты (7 / 14 / 30 / 90 дней)
   - **Исключить уже отправленных** — не добавлять тех, кому уже писали
3. Нажмите **«Собрать контакты»**
4. Приложение пройдёт по чатам и соберёт номера телефонов
5. Когда сбор завершится — база отобразится в списке

**Кнопки:**
- **«Сохранить CSV»** — экспорт в Excel-совместимый файл
- **«Удалить дубликаты»** — убирает повторы
- **«Очистить базу»** — полная очистка списка
- Кнопка ✕ рядом с контактом — удалить одного

---

### Шаг 3 — Сообщения

1. Перейдите в **«Сообщения»**
2. Напишите текст в поле «Вариант 1»
3. Нажмите **«Добавить вариант»** для дополнительных формулировок (до 5 штук)
4. Нажмите **«Сохранить»** — тексты сохраняются и не пропадут после перезапуска

> Система случайно выбирает один из вариантов при каждой отправке — это снижает риск блокировки.

**Предпросмотр:** внизу страницы показывается случайный вариант сообщения.

---

### Шаг 4 — Рассылка

1. Перейдите в **«Рассылка»**
2. Настройте параметры:
   - **Кол-во получателей** — сколько человек получат сообщение
   - **Задержка ОТ/ДО** — пауза между отправками (в секундах)
   - **Безопасный режим** — медленный набор, имитация человека
   - **Пропускать если писали** — не отправлять тем, кому писали N дней назад
3. Нажмите **«Тест»** — отправит одно сообщение первому контакту для проверки
4. Нажмите **«Старт»** — начнётся рассылка

**В процессе:**
- Статистика обновляется в реальном времени (Отправлено / Ошибки / Осталось)
- Лог показывает каждое действие
- Кнопка **«Стоп»** останавливает мгновенно

---

## 6. Рекомендации по безопасности

| Параметр | Рекомендация |
|----------|-------------|
| Сообщений в день | 30–50 |
| Задержка | 60–120 секунд |
| Безопасный режим | Включён |
| Вариантов текста | 3–5 |

- Каждые 10 сообщений приложение автоматически делает паузу 3–5 минут
- При 4 ошибках подряд — автостоп
- Все действия записываются в `logs.txt`

## 7. Возможные ошибки и решения

### «WhatsApp не открыт»
- Убедитесь, что нажали «Открыть WhatsApp»
- Дождитесь подключения (зелёный статус)

### «Список чатов не найден»
- WhatsApp не подключён или загружается
- Подождите 10–15 секунд и попробуйте снова

### «Поле ввода не найдено»
- Номер телефона невалиден или заблокирован в WhatsApp
- Контакт будет пропущен автоматически

### «Номер недействителен»
- Номер не зарегистрирован в WhatsApp
- Приложение автоматически пропускает такие контакты

### Браузер не открывается
```
npx playwright install chromium
```
Переустановите браузер Playwright.

### Приложение не запускается
- Убедитесь что установлен Node.js (команда `node --version`)
- Выполните `npm install` в папке проекта

### Ошибки при сборке .exe
- Обновите npm: `npm install -g npm`
- Пересоберите: `npm run build`

## 8. Рекомендации для слабого ПК

Приложение изначально оптимизировано:
- Один браузер на всё время работы
- Изображения и видео заблокированы (экономия трафика и RAM)
- Минимальная нагрузка на CPU

**Дополнительно:**
- Закройте другие вкладки браузеров
- Закройте лишние программы
- Желательно: 4+ ГБ оперативной памяти
- Если тормозит — увеличьте задержку до 90–180 секунд

---

## 9. Где хранятся данные

Все данные сохраняются локально в папке приложения:
- **contacts.json** — база контактов
- **messages.json** — варианты текстов
- **send_history.json** — кому и когда писали
- **logs.txt** — полный лог действий
- **wa_session/** — сохранённая сессия WhatsApp

Нажмите «Папка данных» в боковом меню — откроется папка с файлами.

---

## 10. Сценарий тестирования

1. Подключиться → зелёный статус
2. Собрать контакты → проверить список
3. Написать 2–3 варианта сообщения → сохранить
4. Нажать «Тест» → убедиться что первый контакт получил сообщение
5. Настроить: 10 человек, 30–60 секунд
6. Нажать «Старт» → наблюдать статистику
7. На 5-м сообщении нажать «Стоп»
8. Закрыть и перезапустить → данные сохранились
