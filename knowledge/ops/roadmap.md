# Roadmap

This roadmap is intentionally future-facing. It does not authorize implementation during FOUNDATION stage.

## Future Systems

- AI auto mode: AI can proactively assist within strict manager-approved boundaries.
- Suggest mode: AI suggests replies/products without taking action.
- Handoff mode: AI prepares context for a human manager to continue.
- Voice transcription: convert voice notes or spoken manager input into structured text.
- Image support: product/customer image context for search and recommendations.
- Advanced recommendations: better product ranking, alternatives, and stock-aware suggestions.
- AI CRM memory: persistent customer preferences and interaction memory with privacy controls.
- Analytics: campaign, response, product interest, and search performance reporting.
- Advanced search: stronger model/color/material parsing, typo tolerance, and explainable ranking.

## Foundation Prerequisites

Before implementing roadmap items:
- restore/use git backup workflow;
- add snapshots for current stable behavior;
- add parser/search examples;
- add diagnostics for risky systems;
- define privacy and data retention rules for persistent AI memory.
