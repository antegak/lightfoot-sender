# /update-knowledge

Purpose: keep project memory and documentation current after changes.

Update:
- relevant `knowledge/core` docs;
- relevant `knowledge/features` docs;
- relevant `knowledge/ops` docs;
- `knowledge/tasks` active/backlog/completed;
- `CHANGELOG.md`;
- roadmap when future work changes;
- snapshots when behavior, architecture, release, IPC, parser/search, or data flow changes.

Output:
- docs changed;
- source changes reflected;
- gaps still unknown;
- confidence score.
